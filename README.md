# 📈 Т-Инвестиции × DeepSeek — AI-ассистент по портфелю

Приложение, в котором можно **спросить про свой портфель обычным языком** и получить ответ по реальным цифрам:
DeepSeek сам решает, какие данные запросить у T-Invest API через **Function Calling** (счета, портфель,
операции, свечи, цены, фундаментальные показатели `GetAssetFundamentals`), и формирует ответ.

![python](https://img.shields.io/badge/python-3.10%2B-blue)

Это ценовая динамика без дивидендов и купонов; не ИИР.

## Что умеет

- 💬 **Естественный язык вместо API-вызовов.** «Что там по SBER?», «Сколько я пополнил за месяц?»,
  «Какие бумаги из вотчлиста недооценены по P/E и ROE?» — модель сама выбирает инструменты.
- 🔢 **Только реальные цифры.** Любое число берётся из ответа T-Invest API; в системном промпте прямо
  запрещено выдумывать значения. Если API вернул `null` — ассистент скажет «нет данных».
- 🧮 **Арифметика на стороне Python, а не LLM.** Стоимость позиции, доля в портфеле, P/L в ₽ и %,
  изменение цены за период считаются в коде и отдаются модели готовыми.
- 📊 **Фундаментальные показатели** через `GetAssetFundamentals`: P/E, P/B, P/S, EV/EBITDA, ROE, ROA, ROIC,
  EPS, маржа, выручка, чистая прибыль, EBITDA, капитализация, дивидендная доходность, payout ratio,
  долг/капитал, бета, 52-недельный диапазон, темпы роста.
- 🖥 **Два интерфейса:** CLI-чат на `rich` (запуск одной командой) и Streamlit-веб с кнопками-подсказками.
- 🔒 **Read-only.** Используется только токен «только чтение»; торговых методов в коде нет вообще.
- 🧪 **Демо-режим** на синтетических данных: можно посмотреть продукт без токенов Т-Банка и DeepSeek.
- ⚙️ Ретраи с экспоненциальной задержкой, TTL-кэш рыночных данных, логирование с вырезанием секретов,
  143 unit-теста на моках (включая smoke-тест Streamlit через `AppTest`).

## Приёмочные сценарии

| Вопрос пользователя | Что вызывает модель | Что получается |
|---|---|---|
| «Покажи портфель» | `get_portfolio` | таблица позиций: кол-во, средняя и текущая цена, стоимость, доля, P/L в ₽ и %, денежные остатки, итог |
| «Какая бумага дала лучшую доходность за месяц?» | `get_performance{days:30}` | рейтинг по дневным свечам, лидер и аутсайдер, вклад в рублях, взвешенная доходность портфеля |
| «Что там по SBER?» | `get_instrument_info` + `get_fundamentals` + `get_candles` | цена, динамика за 30 дней, мультипликаторы, дивидендная доходность, капитализация |
| «Сколько пополнил за месяц?» | `get_cash_flows{days:30}` | пополнения, выводы, `net_deposits`, отдельно дивиденды/купоны/налоги/комиссии |
| «Какие бумаги из вотчлиста недооценены по P/E и ROE?» | `get_watchlist` → `get_fundamentals` | таблица P/E · P/B · ROE · див. доходность и **интерпретация модели**: низкий P/E при высоком ROE = потенциальная недооценка, бумаги с отрицательным P/E отмечены отдельно |

Все пять сценариев покрыты тестами (`tests/test_demo_offline.py::test_acceptance_scenarios`) и работают
как с живой моделью, так и в демо-режиме. Реальный вывод по каждому вопросу (на демо-данных) —
в [`docs/EXAMPLE_SESSION.md`](docs/EXAMPLE_SESSION.md).

## Быстрый старт (3 шага)

Нужен Python **3.10+**.

```bash
# 1. Зависимости
git clone https://github.com/<ваш-аккаунт>/tinvest-deepseek-assistant.git
cd tinvest-deepseek-assistant
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Конфигурация
cp .env.example .env
$EDITOR .env      # вставьте TINVEST_TOKEN и DEEPSEEK_API_KEY

# 3. Запуск
python -m tinvest_ai
```

Где взять токены:

| Токен | Где получить |
|---|---|
| `TINVEST_TOKEN` | Приложение «Инвестиции» → профиль → **Настройки → Токены для API**. Для песочницы — отдельный токен в разделе **Песочница**. Достаточно прав «только чтение». |
| `DEEPSEEK_API_KEY` | [platform.deepseek.com](https://platform.deepseek.com) → API keys |

> ⚠️ По умолчанию `TINVEST_SANDBOX=true` — приложение работает с **песочницей**. Реальные данные счёта
> включаются только при `TINVEST_SANDBOX=false`.

Если ключей нет — приложение не упадёт, а поднимется в **демо-режиме** (см. ниже).

## Демо-режим без ключей

```bash
DEMO_MODE=true python -m tinvest_ai      # или: python -m tinvest_ai --demo
```

- синтетический портфель (SBER, GAZP, LKOH, YDEX, OZON, TMOS), операции, свечи и фундаменталка;
- ответы строит `OfflineAgent` — детерминированные сценарии поверх **тех же инструментов**;
- ни одного внешнего запроса: можно показывать на созвоне, в CI, на Railway без секретов.

Демо включается автоматически, если `TINVEST_TOKEN`/`DEEPSEEK_API_KEY` не заданы.
Цифры вымышленные — это не котировки Мосбиржи.

## Как это работает

```
вопрос пользователя
        │
        ▼
┌──────────────────────┐   tools (JSON Schema)   ┌────────────────────────┐
│  DeepSeek chat       │ ◀────────────────────── │  tools.py              │
│  api.deepseek.com    │ ──────────────────────▶ │  11 инструментов       │
└──────────────────────┘   tool_calls            └───────────┬────────────┘
        ▲                                                    │
        │  role=tool: результат в JSON                       ▼
        │                                        ┌────────────────────────┐
        └─────────────────────────────────────── │ tinvest_client.py      │
                                                 │ (read-only, retry,кеш) │
                                                 └───────────┬────────────┘
                                                             │ gRPC
                                                             ▼
                                                   T-Invest API (sandbox)
```

Цикл (`tinvest_ai/agent.py`):

1. отправляем в DeepSeek историю диалога + системный промпт + схемы инструментов;
2. если ответ содержит `tool_calls` — выполняем каждый вызов, результат кладём сообщением
   `role="tool"` с тем же `tool_call_id`;
3. повторяем, пока модель не ответит текстом (не более `MAX_TOOL_ROUNDS` раундов;
   после лимита просим финальный ответ **без** инструментов);
4. ответ и вопрос сохраняются в историю (последние `HISTORY_LIMIT` сообщений).

Что видит модель в результате вызова — уже посчитанные данные:

```json
{
  "ticker": "SBER", "quantity": 400.0, "average_price": 265.4, "current_price": 318.75,
  "value": 127500.0, "invested": 106160.0, "expected_yield": 21340.0,
  "expected_yield_pct": 20.1, "share_in_portfolio_pct": 21.0, "currency": "RUB"
}
```

Пример фундаменталки (`get_fundamentals`): `pe_ratio_ttm`, `price_to_book_ttm`, `roe` **и** `roe_pct`
(проценты отдаются в двух формах, чтобы модель не путала коэффициент с процентом),
`dividend_yield_daily_ttm_pct`, `market_capitalization`, `eps_ttm`, `total_debt_to_equity_mrq` и т.д.

Подробности решений — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Инструменты (Function Calling)

| Инструмент | Что отдаёт | Зачем модели |
|---|---|---|
| `list_accounts` | счета: id, название, тип, статус | выбрать счёт, если их несколько |
| `get_portfolio` | позиции + стоимость + P/L + доли + кэш | «покажи портфель» |
| `get_operations` | операции за период (фильтр по типам, лимит) | разбор истории, сделки |
| `get_cash_flows` | агрегаты: пополнения/выводы/дивиденды/купоны/налоги/комиссии | «сколько пополнил» |
| `get_performance` | доходность по бумагам, лидер/аутсайдер, веса | «лучшая доходность» |
| `search_instrument` | поиск по тикеру/названию | найти бумагу по-человечески |
| `get_instrument_info` | карточка: лот, валюта, тип, биржа, ISIN, цена | «что там по SBER» |
| `get_fundamentals` | P/E, P/B, P/S, EV/EBITDA, ROE, ROA, ROIC, EPS, маржа, капитализация, дивиденды, долг, бета… | сравнение и скрининг |
| `get_candles` | свечи + сводка изменения цены | динамика, произвольный период |
| `get_last_prices` | последние цены списком (батч) | быстрый снимок цен |
| `get_watchlist` | вотчлист из `WATCHLIST` + цены | сценарий «недооценённые бумаги» |

Показать список в CLI: `/tools`. Все описания — в `tinvest_ai/tools.py`.

## Переменные окружения

Полный список с комментариями — в [`.env.example`](.env.example). Самое важное:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TINVEST_TOKEN` | — | **обязательно**, read-only токен Т-Инвестиций |
| `TINVEST_SANDBOX` | `true` | `true` — песочница, `false` — боевой контур |
| `TINVEST_ACCOUNT_ID` | — | счёт по умолчанию (иначе первый доступный) |
| `DEEPSEEK_API_KEY` | — | **обязательно**, ключ DeepSeek |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | OpenAI-совместимый endpoint |
| `DEEPSEEK_MODEL` | `deepseek-chat` | поддерживает Function Calling (`deepseek-reasoner` — нет) |
| `WATCHLIST` | пусто | тикеры для сценария «недооценённые» |
| `DEMO_MODE` | `false` | синтетические данные без ключей |
| `STREAM` | `false` | ответ токенами по мере генерации |
| `MAX_TOOL_ROUNDS` | `8` | лимит раундов вызова инструментов |
| `API_RETRIES` | `3` | попытки на один вызов API |
| `CACHE_TTL` | `60` | TTL кэша цен/свечей, сек (0 — выключить) |
| `LOG_LEVEL` | `INFO` | уровень логов |

## Запуск: CLI и Streamlit

### CLI-чат (rich)

```bash
python -m tinvest_ai                                   # интерактивный чат
python -m tinvest_ai --ask "покажи портфель"           # один вопрос и выход
python -m tinvest_ai --demo                            # демо-данные
python -m tinvest_ai --stream                          # печать ответа по токенам
python -m tinvest_ai --show-config                     # конфигурация без секретов
python -m tinvest_ai --log-level DEBUG --log-file logs/app.log
```

Команды в чате: `/help`, `/accounts`, `/tools`, `/config`, `/debug` (показать сырые ответы инструментов),
`/reset`, `/exit`.

### Streamlit

```bash
streamlit run streamlit_app.py        # http://localhost:8501
```

В сайдбаре: переключатель демо-режима, быстрые вопросы, проверка счетов, список инструментов,
конфигурация с замаскированными секретами. Под каждым ответом — раскрывающийся список вызовов
инструментов с JSON (видно, откуда взялись цифры).

## Деплой на Railway

Репозиторий готов к деплою «из коробки»: `Dockerfile` + `railway.json` (healthcheck `/_stcore/health`,
рестарт при падении). Streamlit слушает `$PORT`, который Railway подставляет сам.

### Пошагово

1. **Залейте репозиторий на GitHub** (см. ниже), затем на [railway.com](https://railway.com):
   `New Project → Deploy from GitHub repo → выбрать репозиторий`.
   Railway увидит `Dockerfile` и соберёт образ (2–3 минуты).

2. **Переменные окружения** — вкладка **Variables** у сервиса:

   ```
   TINVEST_TOKEN      = t.xxxxxxxxxxxxxxxx
   DEEPSEEK_API_KEY   = sk-xxxxxxxxxxxxxxxx
   TINVEST_SANDBOX    = true
   WATCHLIST          = SBER,GAZP,LKOH,YDEX,OZON
   LOG_LEVEL          = INFO
   ```

   `PORT` задавать **не нужно** — Railway инжектит его сама.

3. **Публичный домен**: `Settings → Networking → Generate Domain`.
   Открывается Streamlit-интерфейс; статус сервиса Railway считает по `/_stcore/health`.

4. **Без ключей** сервис всё равно поднимется в демо-режиме — удобно проверить, что деплой живой,
   и уже потом добавить секреты (после изменения Variables Railway перезапустит сервис автоматически).

### Если собираете через Nixpacks (без Dockerfile)

Удалите/отключите `railway.json` (или поставьте `builder: NIXPACKS`) — останется `Procfile`,
команда запуска та же. Зависимости поставятся из `requirements.txt`
(в нём уже прописан `--extra-index-url` на реестр Т-Банка).

### Проверка после деплоя

- `/` → интерфейс, в сайдбаре видно «ПЕСОЧНИЦА» (или «ДЕМО», если ключей нет);
- кнопка **Счета** в сайдбаре → JSON со списком счетов песочницы;
- вопрос «покажи портфель» → таблица или честное «портфель пуст»
  (в песочнице позиции появляются только после покупок внутри песочницы).

### CLI на Railway

Railway — не интерактивный терминал, поэтому CLI-чат логичнее гонять локально (или в
`docker run -it`). Если нужен разовый вопрос «в облаке» — сделайте отдельный сервис с командой:

```bash
python -m tinvest_ai --ask "какая бумага дала лучшую доходность за месяц" --no-stream
python -m tinvest_ai --show-config        # проверить, что переменные доехали
```

### Docker локально

```bash
docker build -t tinvest-deepseek-assistant .
docker run --rm -p 8501:8501 --env-file .env tinvest-deepseek-assistant
```

### Публикация на GitHub

```bash
git init && git add . && git commit -m "feat: T-Invest × DeepSeek assistant"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/tinvest-deepseek-assistant.git
git push -u origin main
```

`.env` в `.gitignore` — секреты не уедут в репозиторий. Проверить историю можно так:
`git log -p | grep -i -E "t\.[a-z0-9]{20,}|sk-[a-z0-9]{20,}"` (пусто = хорошо).

| `test_agent.py` | tool loop, стриминг (в т.ч. сборка `tool_calls` из дельт), лимит раундов, история, ошибки API |
| `test_demo_offline.py` | демо-данные и все пять приёмочных сценариев |

из SDK, `FakeOpenAI` — ответы DeepSeek. SDK Т-Инвестиций для тестов не требуется.

## Обработка ошибок, ретраи, логи

**Ретраи** (`retry.py`): экспоненциальная задержка с полным jitter, по умолчанию 3 попытки.
Повторяются только «шумные» ошибки — `UNAVAILABLE`, `DEADLINE_EXCEEDED`, `RESOURCE_EXHAUSTED`,
`INTERNAL`, `ABORTED` и сетевые исключения. Ошибки валидации пробрасываются сразу.

**Ошибки инструментов не ломают чат**: исключение превращается в
`{"error": "tool_failed", "message": "...", "hint": "..."}` и уходит модели как результат вызова —
она объясняет пользователю, что пошло не так («тикер не найден», «нет доступа к счёту»).
На уровне CLI/веба любая ошибка DeepSeek (`401`, `402`, `429`, таймаут, сеть) переводится
в понятный текст с подсказкой, что чинить.

**Логи без секретов**: фильтр вырезает точные значения токенов, строки вида `t.xxxx`/`sk-xxxx`,
`Authorization: ...`, `Bearer ...`, `token=...`. Логгеры `httpx`/`openai`/`grpc` принудительно
поднимаются до `WARNING`, чтобы заголовки запросов не попадали в DEBUG-вывод. Удобно проверить:

```bash
python -m tinvest_ai --log-level DEBUG --ask "покажи портфель" 2>&1 | grep -i -E "bearer|sk-|t\.[a-z0-9]{10}" || echo "секретов в логах нет"
```

## Ограничения и важные заметки

1. **Про SDK.** Пакет `tinkoff-investments` на PyPI с марта 2025 помечен как *quarantined*
   и больше не устанавливается. Актуальный официальный SDK — **`t-tech-investments`**
   (импорт `t_tech.invest`), он живёт в реестре Т-Банка; см. `requirements-sdk.txt`
   (подключается из `requirements.txt`, отдельной командой ставить не нужно).
   Сертификат реестра выпущен «Russian Trusted Sub CA» (Минцифры) и отсутствует в стандартном
   наборе корневых сертификатов, поэтому в `requirements-sdk.txt` для этого хоста указан
   `--trusted-host`. Более строгий вариант — поставить корневой сертификат Минцифры в систему
   и убрать `--trusted-host`.
   Слой `tinvest_ai/sdk.py` поддерживает оба пакета (`t_tech.invest` и `tinkoff.invest`),
   поэтому код менять не придётся. Запасной путь, если реестр недоступен совсем:

   ```bash
   pip install "tinkoff-investments @ git+https://github.com/RussianInvestments/invest-python.git"
   ```

   Именно так поступает `Dockerfile`: если установка из реестра Т-Банка падает, SDK ставится
   из GitHub — сборка на Railway не ломается.
2. **Песочница ≠ реальный счёт.** В песочнице нет позиций, пока вы их не купите внутри песочницы;
   котировки и фундаменталка там доступны. Для реальных данных — `TINVEST_SANDBOX=false`
   (токен должен иметь доступ к боевому контуру).
3. **Доходность в `get_performance` — ценовая**, без дивидендов и купонов. Это явно написано
   и в ответе инструмента, и в системном промпте.
4. **Проценты.** API отдаёт рентабельности коэффициентом (`0.241`); приложение отдаёт и коэффициент,
   и `*_pct`. Эвристика «`|x| ≤ 1.5` → коэффициент» описана в `docs/ARCHITECTURE.md`.
5. **Лимиты API.** Фундаменталка — батчем до 100 активов; цены — батчем; свечи кэшируются на `CACHE_TTL`.
   `get_performance` делает по одному запросу свечей на бумагу (ограничено `MAX_PERFORMANCE_POSITIONS`).
6. **`deepseek-reasoner` не поддерживает Function Calling** — приложение автоматически не передаёт
   ему инструменты, поэтому для ассистента нужен `deepseek-chat`.
7. **Не ИИР.** Ответы носят информационный характер; в промпте заложено напоминание, что это
   не индивидуальная инвестиционная рекомендация.
8. **Один токен на процесс.** Мультипользовательский режим (OAuth Т-Инвестиций, хранение сессий)
   в MVP не реализован.
